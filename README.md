# ChatSketch

> **Note:** Text generation may occasionally hit free tier rate limits on the Gemini API. If the chat doesn't respond, please try again after a few minutes.

ChatSketch is a modern, full-stack AI chat application built with React and Node.js. It allows users to have real-time text-based conversations with an AI and generate creative images from prompts.

## 🚀 Key Features

* **AI Text Generation:** Integrates with a generative AI API for intelligent, context-aware chat responses.

* **AI Image Generation:** Leverages an AI API to create unique images from user prompts.

* **User Authentication:** Secure user login and registration using JWT (JSON Web Tokens).

* **Full-Stack Architecture:** A complete monorepo with a React frontend (Vite) and a Node.js/Express backend.

* **MongoDB Database:** Uses MongoDB and Mongoose to store user data, chat history, and messages.

* **Community Gallery:** Users can publish their generated images to a public community feed.

* **Custom UI:** Styled with Tailwind CSS for a sleek, responsive, and modern dark-mode-first design.

## 🛠️ Tech Stack

### Frontend

* **React** (with Vite)

* **Tailwind CSS**

* **Axios**

* **react-hot-toast**

### Backend

* **Node.js**

* **Express**

* **MongoDB** (with Mongoose)

* **JSON Web Tokens (JWT)**

* **Generative AI API**

* **ImageKit**
